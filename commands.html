Before you come

Show up installed.

The venue Wi-Fi will be shared by a hundred people downloading the same model, so do this at home. If you can't, grab a USB drive from a TA.

  1. Install Ollama from ollama.com/download and open it once.
  2. Install Node.js 20.6 or newer, and git.
  3. Pull both models (about 7 GB together):
terminal
$ ollama pull llama3.2:3b
$ ollama pull qwen2.5:7b
$ node --version
Checkpoint 0110 min

Wake it up.

terminal
$ ollama pull llama3.2:3b
$ ollama run llama3.2:3b
inside ollama
>>> /set system You only answer in haiku.
>>> what is a hackathon
>>> /bye

Then swap in qwen2.5:7b. Slower, smarter. Feel the difference in your fans. On an 8 GB laptop, unload the 3B first so the two don't fight over memory:

terminal
$ ollama stop llama3.2:3b
$ ollama run qwen2.5:7b
Checkpoint 027 min

Surprise: it speaks OpenAI.

mac / linux
$ curl http://localhost:11434/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{"model": "qwen2.5:7b", "messages": [{"role": "user", "content": "playfully roast my laptop"}]}'
windows powershell
$ $body = '{"model": "qwen2.5:7b", "messages": [{"role": "user", "content": "playfully roast my laptop"}]}'
$ Invoke-RestMethod http://localhost:11434/v1/chat/completions -Method Post -ContentType "application/json" -Body $body

Same request shape as OpenAI's API. Anything that talks to OpenAI can talk to this. No GPU? The answer can take 20 to 40 seconds, so be patient.

what's loaded, and how much memory it's eating
$ ollama ps
Measure it

Vibes are not a benchmark.

terminal
$ ollama run qwen2.5:7b --verbose
inside ollama
>>> explain recursion in one line

Read the eval rate line. That's your tokens per second. Small models fall over on multi-step reasoning, strict JSON and tool calls, and facts they never saw. Pick the smallest model that passes your test.

Checkpoint 0315 min

Give your agent a local brain.

mac / linux
$ git clone https://github.com/shourya0523/hack1984-local-agent
$ cd hack1984-local-agent
$ cp .env.example .env
$ npm start
windows
$ git clone https://github.com/shourya0523/hack1984-local-agent
$ cd hack1984-local-agent
$ copy .env.example .env
$ npm start
.env (already set for you)
# .env
BASE_URL=http://localhost:11434/v1
API_KEY=ollama
MODEL=qwen2.5:7b

Use the 7B. The 3B fumbles tool calls. Not connecting? npm run check says what's wrong.

Checkpoint 03, part two

Give it hands.

Add one tool to tools.js that only your laptop can answer: read a file in ~/notes, search a folder you'd never upload, or check your battery. Restart and ask something that needs it. A red [tool] line means it worked.

paste inside the tools array
{
  name: "read_note",
  description: "Read a text file from the user's ~/notes folder.",
  parameters: {
    type: "object",
    properties: { filename: { type: "string", description: "e.g. ideas.md" } },
    required: ["filename"],
  },
  run: async ({ filename }) =>
    (await import("node:fs/promises")).readFile(
      (await import("node:path")).join((await import("node:os")).homedir(), "notes", filename), "utf8"),
},

$ npm start
Stuck

Something broke. Obviously.

ProblemFix
The Wi-Fi diedGrab a USB drive from a TA. Installers and both models are on it; follow README.txt.
Laptop is wheezingRun ollama ps, then ollama stop the model you're not using. Still slow? Drop to llama3.2:3b and close Chrome.
Laptop says noUse the Groq fallback below. The key is on the whiteboard.
You fell behindgit checkout checkpoint-3 for a working agent.
WindowsRaise your hand. We have a person for this.
groq fallback, replace the three lines in .env
BASE_URL=https://api.groq.com/openai/v1
API_KEY=paste-the-key-from-the-whiteboard
MODEL=llama-3.3-70b-versatile
NoteThe fallback sends your prompts to Groq, which is the opposite of the point. Switch back when you can. The shared key is revoked after closing on Sunday.
